请生成 三层结构时严格遵守以下规范：
- 针对entity目录下的所有实体类，表现层controller目录中产生对应Controller文件，类名后缀必须以 Controller结尾
- 表现层Controller类，必须添加 @RestController 注解，不需要添加任何的业务方法
- 针对entity目录下的所有实体类，业务层service目录中产生对应interface业务接口，业务接口名称前缀必须以I开头
- 并且在service目录中，创建impl子目录，在impl子目录中分别进行业务接口实现，实现类去掉前缀I，添加后缀Impl
- 所有的业务实现类,必须添加 @Service 注解，不需要添加任何的业务方法
- 所有表现层Controller类，使用final构造装配模式，完成业务接口的DI依赖注入，属性名称后缀添加Impl
- 所有业务层ServiceImpl类，使用final构造装配模式，完成Mapper接口的DI依赖注入，属性名称后缀添加Mapper
- 添加注释时，必须通俗易懂，简单明了，不能使用专业术语，只能使用普通语言

请生成 Mapper映射时严格遵守以下规范：
- 针对entity目录下的所有实体类，在源代码目录下的 mapper子目录中，生成对应的Mapper.java接口，接口名后缀必须以 Mapper结尾（例如：UserMapper、OrderMapper）；
- 针对entity目录下的所有实体类，在源配置目录下的 mapper子目录，生成对应的Mapper.xml 文件，并且在配置文件中，添加以下代码 ，修改，namespace属性，关联对应的Mapper接口
- Mapper.java接口中，不需要添加任何的业务方法
- Mapper.xml文件中，不需要添加任何的SQL映射实现
- Mapper.java接口中，添加@Mapper注解，用于开启Mapper扫描功能
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper
PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
"https://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.iwe3.项目名称.mapper.UserMapper">
</mapper>

请生成 Java 实体类时严格遵守以下规范：
- 类名后缀必须以 Entity结尾（例如：UserEntity、OrderEntity）；
- 所有属性必须使用 private 修饰符；
- 类上必须添加 Lombok 注解 @Data 和 @Builder 和 @NoArgsConstructor 和 @AllArgsConstructor；
- 不要生成 getter/setter/toString 等方法（由 @Data 自动生成）；
- 使用标准 Java Bean 风格，属性名采用小驼峰命名；
- 不要包含业务逻辑，仅作为数据载体;
- 所有基本数据类型属性，必须使用包装类;
- 日期类型统一使用java.util.Date类型。

请生成表现层接口响应时严格遵守以下规范：
- 表现层（Controller）所有接口必须统一返回 Result 类。
- Result 类必须包含状态码（code）、提示信息（message）和响应数据（data）三个核心字段。
- 禁止在 Controller 层直接返回实体类对象、Map 或基本数据类型。
